# Nursery Mode

**Nursery Mode** is a simplified, **fullscreen** view with **large buttons**,
designed for two situations:

- **Nighttime feeds** — minimal, low-distraction screen you can use half-asleep.
- **A shared device** — a tablet mounted in the nursery that anyone can tap
  without navigating menus.

## How to open it

- From the **side menu** → **Nursery Mode**, or
- via **Quick Search** (`Ctrl/Cmd + K`) → type `nursery`.

## What it's good for

- **Big, easy taps** for the most common actions, so logging a feed or a diaper
  in the dark is quick and error-free.
- **Less clutter** than the full dashboard — just the essentials.

## Leaving Nursery Mode

Use the on-screen control to exit back to the normal app when you're done.

> **Tip:** combine Nursery Mode with the **dark theme** for the dimmest possible
> screen at night. Toggle the theme from Settings or Quick Search → *Toggle
> Light/Dark Theme*.
