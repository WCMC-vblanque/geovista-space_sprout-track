# Modo Guardería (Nursery Mode)

[← Volver al manual](README.md)

El **Modo Guardería** es una vista simplificada, a **pantalla completa**, con
**botones grandes**, pensada para dos situaciones:

- **Tomas nocturnas** — pantalla mínima y sin distracciones que puedes usar medio
  dormido/a.
- **Un dispositivo compartido** — una tablet montada en el cuarto que cualquiera
  puede tocar sin navegar por menús.

## Cómo abrirlo

- Desde el **menú lateral** → **Nursery Mode**, o
- con la **Búsqueda Rápida** (`Ctrl/Cmd + K`) → escribe `nursery`.

## Para qué sirve

- **Toques grandes y fáciles** para las acciones más comunes, así registrar una
  toma o un pañal a oscuras es rápido y sin errores.
- **Menos desorden** que el panel completo — solo lo esencial.

## Salir del Modo Guardería

Usa el control en pantalla para volver a la app normal cuando termines.

> **Tip:** combina el Modo Guardería con el **tema oscuro** para la pantalla más
> tenue posible de noche. Cambia el tema desde Ajustes o la Búsqueda Rápida →
> *Toggle Light/Dark Theme*.
