# Enregistrer des Activités

[← Retour au manuel](README.md)

Tout ce que vous suivez se trouve sur l'écran d'accueil **Log Entry**. Touchez un
bouton d'activité, remplissez le court formulaire et enregistrez — cela apparaît
aussitôt dans la chronologie. Rien n'est enregistré tant que vous ne touchez pas
« enregistrer ».

> **Rappel :** les activités sont enregistrées pour le **bébé sélectionné**. Si
> vous vous occupez de plusieurs bébés, vérifiez d'abord le sélecteur de bébé en
> haut.

## Les boutons d'activité

La rangée de boutons ronds est votre boîte à outils. Vous pouvez les **glisser
pour les réordonner** afin de placer les plus utilisés en premier, et toucher
**Configure** pour afficher ou masquer des boutons.

Les activités disponibles sont :

| Bouton | À utiliser pour |
|--------|-----------------|
| **Sommeil** | Siestes et sommeil de nuit (avec minuteur en direct). |
| **Alimentation** | Sein, biberon ou solides. |
| **Couche** | Changes mouillé / sale / mixte. |
| **Tirage** | Séances de tirage (tire-lait). |
| **Médicament** | Médicaments et doses. |
| **Mesure** | Poids, taille, périmètre crânien, **température**. |
| **Bain** | L'heure du bain. |
| **Note** | Tout ce qui mérite d'être noté. |
| **Activité** | Jeu / temps sur le ventre (avec minuteur). |
| **Étape** | Étapes de développement (premier sourire, retournement…). |
| **Vaccin** | Vaccinations. |

## Sommeil

1. Touchez **Sommeil** quand le bébé s'endort — cela **démarre un minuteur en
   direct** et le bouton indique que le sommeil est en cours.
2. Touchez **End Sleep** (Fin du sommeil) au réveil pour clore la séance.
3. Vous pouvez aussi ajouter un sommeil passé manuellement en ajustant les heures
   de début/fin dans le formulaire.

Le tableau de bord montre la durée de la sieste en cours et le temps écoulé depuis
le dernier sommeil.

## Alimentation

Touchez **Alimentation** et choisissez le type :

- **Sein** — démarrez une séance avec **minuteur en direct**. Vous pouvez
  **changer de côté** (gauche/droite), **mettre en pause** et **reprendre**, puis
  **End Feed** (Fin de la tétée) pour enregistrer le total. Pratique pour savoir
  quel côté a servi en dernier.
- **Biberon** — enregistrez la **quantité** et l'unité (oz / ml) et s'il s'agit de
  lait maternel ou de préparation.
- **Solides** — enregistrez l'aliment et la quantité.

> **Raccourci :** avec la Recherche Rapide, vous pouvez ouvrir le formulaire déjà
> réglé sur le bon type — ex. `Ctrl/Cmd + K` → tapez `sein` / `breast`. Voir
> [Recherche Rapide](quick-search.md).

## Couche

Touchez **Couche** et choisissez **mouillé**, **sale** ou **les deux**, puis
enregistrez. Le tableau de bord suit le temps écoulé depuis le dernier change —
utile pour le contrôle d'hydratation (couches mouillées).

## Tirage

Touchez **Tirage** pour enregistrer une séance de tire-lait : quantité par côté et
durée. Si le suivi du stock de lait maternel est activé dans les Réglages, les
quantités tirées alimentent votre solde de lait stocké.

## Mesure (température comprise)

Touchez **Mesure** pour enregistrer le **poids, la taille/longueur, le périmètre
crânien** ou la **température**. Le poids et la taille alimentent les courbes de
croissance dans [Rapports](history-and-reports.md). La température est pratique
pour suivre une fièvre.

## Médicament

Touchez **Médicament** pour enregistrer un médicament, la dose et l'heure. Gardez
un historique clair de ce qui a été donné et quand — surtout utile quand les
intervenants se relaient.

## Bain, Note, Activité, Étape, Vaccin

- **Bain** — enregistrez l'heure du bain.
- **Note** — texte libre pour tout (humeur, une rougeur, une remarque du
  médecin…).
- **Activité** — jeu ou temps sur le ventre, avec minuteur optionnel.
- **Étape** — consignez les étapes de développement avec leur date.
- **Vaccin** — enregistrez les vaccinations pour tenir un historique de
  vaccination.

## Modifier ou supprimer une entrée

Touchez n'importe quel élément de la **chronologie** pour l'ouvrir. De là, vous
pouvez ajuster les détails ou la date/heure, ou le supprimer. Les modifications
sont enregistrées aussitôt et la chronologie se met à jour.
