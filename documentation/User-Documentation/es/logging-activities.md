# Registrar Actividades

[← Volver al manual](README.md)

Todo lo que registras vive en la pantalla de inicio **Log Entry**. Toca un botón
de actividad, llena el formulario corto y guarda — aparece en la línea de tiempo
enseguida. Nada se guarda hasta que tocas guardar.

> **Recuerda:** las actividades se registran para el **bebé seleccionado**. Si
> cuidas de más de uno, revisa primero el selector de bebé arriba.

## Los botones de actividad

La fila de botones redondos es tu caja de herramientas. Puedes **arrastrarlos
para reordenar** y poner primero los que más usas, y tocar **Configure** para
mostrar u ocultar botones.

Las actividades disponibles son:

| Botón | Para qué sirve |
|-------|----------------|
| **Sueño** | Siestas y sueño nocturno (con cronómetro en vivo). |
| **Alimentación** | Pecho, biberón o sólidos. |
| **Pañal** | Cambios mojado / sucio / mixto. |
| **Extracción** | Sesiones de extracción (sacaleche). |
| **Medicina** | Medicamentos y dosis. |
| **Medición** | Peso, talla, perímetro craneal, **temperatura**. |
| **Baño** | La hora del baño. |
| **Nota** | Cualquier otra cosa que valga la pena recordar. |
| **Actividad** | Juego / tiempo boca abajo (con cronómetro). |
| **Hito** | Hitos del desarrollo (primera sonrisa, gateo…). |
| **Vacuna** | Vacunaciones. |

## Sueño

1. Toca **Sueño** cuando el bebé se duerma — esto **inicia un cronómetro en vivo**
   y el botón indica que el sueño está en curso.
2. Toca **End Sleep** (Fin del sueño) cuando despierte para cerrar la sesión.
3. También puedes añadir un sueño pasado manualmente ajustando las horas de
   inicio/fin en el formulario.

El panel muestra cuánto ha durado la siesta actual y el tiempo desde el último
sueño.

## Alimentación

Toca **Alimentación** y elige el tipo:

- **Pecho** — inicia una sesión con **cronómetro en vivo**. Puedes **cambiar de
  lado** (izquierdo/derecho), **pausar** y **reanudar**, y luego **End Feed** (Fin
  de la toma) para guardar el total. Útil para saber qué lado fue el último.
- **Biberón** — registra la **cantidad** y unidad (oz / ml) y si es leche materna
  o fórmula.
- **Sólidos** — registra el alimento y la cantidad.

> **Atajo:** con la Búsqueda Rápida puedes abrir el formulario ya configurado al
> tipo correcto — ej. `Ctrl/Cmd + K` → escribe `pecho` / `breast`. Ver
> [Búsqueda Rápida](quick-search.md).

## Pañal

Toca **Pañal** y elige **mojado**, **sucio** o **ambos**, y guarda. El panel
lleva la cuenta del tiempo desde el último cambio — útil para el control de
hidratación (pañales mojados).

## Extracción

Toca **Extracción** para registrar una sesión de sacaleche: cantidad por lado y
duración. Si activas el seguimiento de inventario de leche materna en Ajustes,
las cantidades extraídas alimentan tu saldo de leche almacenada.

## Medición (incluida la temperatura)

Toca **Medición** para registrar **peso, talla/longitud, perímetro craneal** o
**temperatura**. El peso y la talla alimentan las curvas de crecimiento en
[Informes](history-and-reports.md). La temperatura es útil para seguir la fiebre.

## Medicina

Toca **Medicina** para registrar un medicamento, la dosis y la hora. Mantén un
historial claro de qué se dio y cuándo — especialmente útil cuando los cuidadores
se turnan.

## Baño, Nota, Actividad, Hito, Vacuna

- **Baño** — registra la hora del baño.
- **Nota** — texto libre para lo que sea (humor, una erupción, un comentario del
  médico…).
- **Actividad** — juego o tiempo boca abajo, con cronómetro opcional.
- **Hito** — captura hitos del desarrollo con su fecha.
- **Vacuna** — registra vacunaciones para llevar un historial de inmunización.

## Editar o eliminar una entrada

Toca cualquier elemento de la **línea de tiempo** para abrirlo. Desde ahí puedes
ajustar los detalles o la fecha/hora, o eliminarlo. Los cambios se guardan al
instante y la línea de tiempo se actualiza.
