# Mode Crèche (Nursery Mode)

[← Retour au manuel](README.md)

Le **Mode Crèche** est une vue simplifiée, en **plein écran**, avec de **gros
boutons**, pensée pour deux situations :

- **Les tétées de nuit** — un écran minimal et sans distraction, utilisable à
  moitié endormi·e.
- **Un appareil partagé** — une tablette fixée dans la chambre que tout le monde
  peut toucher sans naviguer dans les menus.

## Comment l'ouvrir

- Depuis le **menu latéral** → **Nursery Mode**, ou
- via la **Recherche Rapide** (`Ctrl/Cmd + K`) → tapez `nursery`.

## À quoi ça sert

- **De grands appuis faciles** pour les actions les plus courantes, pour
  enregistrer une tétée ou une couche dans le noir, vite et sans erreur.
- **Moins d'encombrement** que le tableau de bord complet — seulement l'essentiel.

## Quitter le Mode Crèche

Utilisez la commande à l'écran pour revenir à l'app normale une fois terminé.

> **Astuce :** combinez le Mode Crèche avec le **thème sombre** pour l'écran le
> plus tamisé possible la nuit. Changez le thème depuis les Réglages ou la
> Recherche Rapide → *Toggle Light/Dark Theme*.

> **Bientôt :** une teinte ambre chaude personnalisable de « veilleuse » est dans
> la [feuille de route](../../../TODO.md) pour être encore plus douce pour le
> sommeil la nuit.
