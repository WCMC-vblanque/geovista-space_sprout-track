# Primeros Pasos

[← Volver al manual](README.md)

Este capítulo te guía para iniciar sesión, orientarte en la pantalla de inicio,
elegir qué bebé estás registrando e instalar la app en tu dispositivo.

## Iniciar sesión

Sprout Track tiene dos formas de iniciar sesión, según cómo se configuró tu
familia.

### ID de acceso + PIN de seguridad (dispositivo familiar compartido)

Ideal para una tablet en la cocina o un teléfono compartido entre cuidadores.

1. Escribe tu **ID de acceso** — un código corto de 2 caracteres por cuidador.
2. Escribe tu **PIN de seguridad** (al menos 6 dígitos).
3. Toca **Go** (Entrar).

> Cada cuidador puede tener su propio ID y PIN, así la app muestra **quién**
> registró cada actividad. Si aún no hay accesos individuales, la familia usa un
> único PIN compartido.

### Correo + Contraseña (cuenta personal)

1. Escribe tu **correo** y **contraseña**.
2. Toca **Sign In** (Iniciar sesión).
3. ¿Olvidaste la contraseña? Toca **Forgot your password?** y sigue el enlace del
   correo para restablecerla.

### ¿Primera vez? Configura tu familia

Si es una familia nueva, tras iniciar sesión te guiará una configuración corta:
nombra tu familia, añade tu primer bebé (nombre, fecha de nacimiento, sexo) y
listo. Puedes cambiar todo esto después — ver
[Editar Datos del Bebé](editing-baby-details.md).

> La fecha de nacimiento puede ser una estimación (ej. una fecha probable de
> parto antes de que nazca) y actualizarse luego cuantas veces haga falta.

## Un recorrido rápido por la pantalla de inicio

Tras iniciar sesión llegas a **Log Entry** — tu panel diario:

- **Barra superior:** el **selector de bebé**, el botón de **Búsqueda Rápida**
  (🔍), tu cuenta/menú y el botón del menú lateral.
- **Botones de actividad:** una fila de botones redondos (Sueño, Alimentación,
  Pañal y más). Toca uno para registrar esa actividad. Puedes **arrastrarlos para
  reordenar** y tocar **Configure** para elegir cuáles se muestran.
- **Línea de tiempo:** debajo de los botones, una lista de todo lo registrado
  hoy, lo más reciente primero. Toca cualquier entrada para verla o editarla.
- **Menú lateral:** ábrelo (arriba a la izquierda) para llegar a Registro
  Completo, Calendario, Informes, Modo Guardería, Ajustes, idioma y cerrar sesión.

## Elegir qué bebé estás registrando

Si tu familia tiene más de un bebé, toca el **selector de bebé** en la barra
superior y elige el correcto. Todo lo que registras, y todo lo que muestran las
pantallas, aplica al **bebé seleccionado**. Con un solo bebé, se selecciona
automáticamente.

## Cambiar de idioma

Sprout Track habla varios idiomas. Cámbialo desde **Ajustes**, el selector de
idioma del menú lateral o la **Búsqueda Rápida** (`Ctrl/Cmd + K` → escribe tu
idioma). Tu elección se recuerda para la próxima vez.

## Tema claro u oscuro

Alterna entre apariencia clara y oscura desde **Ajustes** o vía **Búsqueda
Rápida** → *Toggle Light/Dark Theme*. El tema oscuro va genial para tomas
nocturnas.

## Instalar la app

Sprout Track es una **PWA (aplicación web progresiva)** — puedes instalarla para
que se abra a pantalla completa como una app nativa y siga funcionando con
conexión débil o nula.

- **En teléfono/tablet:** abre el menú del navegador y elige **Añadir a pantalla
  de inicio** / **Instalar**.
- **En computadora (Chrome/Edge):** haz clic en el icono **Instalar** de la barra
  de direcciones, o el menú del navegador → **Instalar Sprout Track**.

Una vez instalada, funciona **sin conexión** y sincroniza tus entradas cuando
vuelves a estar en línea.
